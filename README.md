# LogicTEAM.Доступы (sbe-access)

Консоль доступов для системы SBE: список всех, кто хотя бы раз входил, и роли
человека в тех приложениях, где вы администратор.

- Экран «от человека»: слева список сотрудников с поиском, справа карточка
  выбранного — его роль в каждом приложении, где у вас права администратора.
  Роль меняется прямо в карточке; рядом видно, что человек получает без
  персональной роли (общий доступ приложения).
- Своего сервера у плагина нет: права централизованы в auth-service
  (`app_permissions`, 2026-09-09), плагин работает с ними по JWT приложения
  `access`, который выдаёт ЦУП.
- Тонкие права внутри приложений (папки и подборки Фотобанка, группы и проекты
  ЛИМС) настраиваются там же, где и раньше — в самих плагинах.
